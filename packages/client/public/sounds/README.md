# Sons du jeu (TV / host)

Dépose ici **4 fichiers** (libres de droits) avec **exactement** ces noms :

| Fichier | Quand | Type conseillé |
|---|---|---|
| `lobby.mp3` | salle d'attente + classement | musique d'ambiance **en boucle**, calme |
| `question.mp3` | pendant une question | musique de **suspense en boucle** (ticking, montée) |
| `reveal.mp3` | à la révélation de la réponse | **court** « sting » / accord |
| `podium.mp3` | classement final | **court** jingle de victoire |

- Les fichiers sont servis automatiquement sur `/sounds/…` (inclus au build).
- Un fichier manquant = pas de son pour cette étape (aucune erreur).
- Le son ne sort que sur l'écran **/host/display** (la TV), après avoir cliqué
  **« Activer le son »** (obligatoire : les navigateurs bloquent l'audio
  automatique). Un bouton 🔊/🔇 permet de couper.

## Où trouver des musiques libres de droits

- **Pixabay Music** (pixabay.com/music) — gratuit, sans attribution.
- **Mixkit** (mixkit.co/free-stock-music + free-sound-effects) — gratuit.
- **Free Music Archive** / **Incompetech** (Kevin MacLeod, CC-BY — créditer l'auteur).

Cherche par ex. « game show », « quiz », « suspense », « countdown », « victory ».
Convertis en `.mp3` si besoin et renomme selon le tableau ci-dessus.
